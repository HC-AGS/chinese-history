# 秦

## 嬴政
- **传记**：出生于赵国邯郸，早年生活在充满阴谋与危险的敌国环境中。在吕不韦的辅佐下年幼登基，在经历权力洗礼后迅速掌控秦国。他不仅是一个冷酷的征服者，更是中国两千年政治格局的奠基人。他通过商鞅变法的法家体系，将秦国打造成一台高效的战争机器。在统一六国后，他试图通过制度的绝对统一（书同文、车同轨）来消除分裂的根源。晚年因恐惧死亡而痴迷于寻找长生不老药，导致其性格日益偏执，推行严苛之法，使其帝国在失去他后迅速崩溃。
- **核心事件志**：
    - **统一六国 (前230-前221)**：通过外交分化与军事打击，先后灭韩、赵、魏、楚、燕、齐。
    - **焚书坑儒 (前213-前212)**：为统一思想，下令焚毁除医药、占卜、农书外的诸子百家书籍，坑杀四百六十余名方士与儒生。
    - **建立郡县制 (前221)**：彻底废除分封制，全国划分为郡县，由中央直接任命官员。
- **战争档案**：
    - **统一战争**：对战六国
    结果：全面胜利，建立大一统帝国。
    - **北击匈奴**：蒙恬率三十万大军收复河套
    结果：削弱匈奴，确立北方边防。
- **基建志**：
    - **万里长城 (前215年起)**：连接秦、赵、燕长城，旨在防御北匈奴。
    - **灵渠 (前214年)**：沟通湘江与漓江
    目的：支撑军队南征百越。
    - **阿房宫/骊山陵**：极度奢侈的权力标志，耗费巨量民力。

## 胡亥
- **传记**：秦始皇第十八子，性格软弱且残忍。在赵高与李斯的合谋下，通过篡改遗诏杀兄扶苏夺权。登基后完全沦为赵高的傀儡，将秦始皇时期的严刑峻法进一步极端化。他在位期间大肆屠戮功臣，制造恐怖气氛，导致帝国统治基础彻底崩溃。其统治的特点是"昏庸与残暴"的结合，加速了秦朝的灭亡。
- **核心事件志**：
    - **篡改遗诏 (前210)**：在赵高的操纵下掩盖扶苏的遗诏，强行登基。
    - **清洗功臣**：在赵高的挑唆下，通过诬陷杀掉包括李斯在内的大量朝廷重臣。
- **战争档案**：
    - **镇压农民起义**：面对陈胜吴广起义
    结果：反应迟钝，未能有效压制。

## 子婴
- **传记**：秦三世，在位46天。关于其身世史学界尚有争议，《史记》记载不一，一说为秦始皇之孙（扶苏之子），一说为秦始皇之弟。在赵高杀死胡亥后，被立为秦王。他虽然试图通过宽政挽回民心，但此时秦朝已失去所有基层控制力。在刘邦军队进入咸阳后，他意识到大势已去，选择投降。
- **核心事件志**：
    - **投降刘邦 (前206)**：在咸阳城内投降，标志着秦朝在法律与制度上的终结。

# 汉

## 西汉

### 刘邦 (高祖)
- **传记**：中国历史上极少数出身平民的开国皇帝。他具备极强的政治实用主义倾向，能够忍辱负重且兼容并蓄。在楚汉之争中，他通过萧何的后勤、张良的谋略、韩信的军事，击败了勇猛但孤傲的项羽。登基后，他意识到郡县制与分封制的矛盾，采取了"郡国并行制"，在维护统一的同时兼顾分封，以换取政权的初步稳定。
- **核心事件志**：
    - **约法三章 (前206)**：进入咸阳后迅速简化秦律
    结果：迅速赢得民心。
    - **垓下之战 (前202)**：彻底击败项羽
    结果：统一中国。
- **战争档案**：
    - **楚汉战争**：对战项羽
    结果：胜利，建立汉朝。
- **基建志**：
    - **未央宫**：西汉的权力核心，规模宏大，象征着新帝国的起点。

### 刘盈 (惠帝)
- **传记**：刘邦之子。天性仁慈，面对吕后对政敌的残酷杀戮深感厌恶。由于性格过于温良，在政治斗争中完全被母亲吕后掌控，成为了一个没有实权的傀儡皇帝，早年抑郁而终。

### 刘恒 (文帝)
- **传记**：汉朝的稳固者。他深刻反思秦朝的暴政，推行"无为而治"和"轻徭薄赋"。他在位期间极其节俭，甚至拒绝修建华丽的宫殿，致力于恢复农业生产和人口增长。通过这种温和的统治方式，他为后来的武帝盛世提供了雄厚的物质基础。
- **核心事件志**：
    - **除肉刑 (前170s)**：废除残酷的肢体刑罚
    结果：改善社会风气。
    - **文景之治**：与景帝共同开启的经济恢复期。

### 刘启 (景帝)
- **传记**：文帝之子，性格比父辈刚毅。在维持经济恢复的同时，他敏锐地觉察到诸侯王势力的威胁。
- **主要战争**：**平七国之乱 (前154)**
    结果：彻底削弱诸侯王权力，强化中央集权。

### 刘彻 (武帝)
- **传记**：汉朝最伟大的扩张者。他摒弃了先辈的无为而治，转而采取积极进取的战略。他通过董仲舒的建议，将儒家思想法定化，建立了高度集权的意识形态体系。他在军事上采取极端进攻姿态，不仅通过卫青、霍去病摧毁了匈奴的优势，还开辟了通往中亚的丝绸之路。然而，其巨大的财政开支导致后期出现严重的社会危机，晚年下《轮台诏》承认政策过激。
- **核心事件志**：
    - **罢黜百家，独尊儒术 (前136)**：将儒学确立为官方正统思想。
    - **盐铁官营**：通过国家垄断战略资源，支撑庞大的战争费用。
- **战争档案**：
    - **漠北之战**：对战匈奴
    结果：大胜，匈奴北迁。
    - **西域开拓**：张骞出使西域
    结果：开通丝绸之路。
- **基建志**：
    - **太学**：建立国家最高学术机构，培养儒家官员。

### 刘弗陵 (昭帝) / 刘询 (宣帝) / 刘奭 (元帝) / 刘骜 (成帝) / 刘欣 (哀帝) / 刘衎 (平帝)
- **阶段传记**：
    - **昭帝 (刘弗陵)**：年幼继位，霍光辅政，延续武帝后期的休养生息政策。
    - **宣帝 (刘询)**：出身民间，在位期间政治稳健，被认为是西汉后期的中兴之主，史称"昭宣中兴"。
    - **元帝 (刘奭)**：柔仁好儒，外戚与宦官势力开始抬头。
    - **成、哀、平帝**：权力迅速转移至外戚（尤其是王氏家族），皇帝沦为名义上的统治者，政治体制陷入腐朽。平帝刘衎年幼继位，被王莽掌控。

### 王莽 (新朝)
- **传记**：一个极端理想主义的篡位者。他利用外戚身份和儒家"圣人"的包装篡汉。他在位期间试图通过"王田制"取消土地私有，以及频繁的货币改革来恢复周礼时期的理想社会。但这些政策完全违背了地主阶级利益且执行脱离实际，最终引发大规模农民起义（绿林赤眉），导致新朝迅速覆灭。
- **核心事件志**：
    - **篡汉立新 (公元8年)**：建立新朝。
    - **王莽改制**：一系列激进的土地和货币改革
    结果：全面失败。

## 东汉

### 刘秀 (光武帝)
- **传记**：东汉的重建者。在群雄割据的乱世中，他以温和的姿态在昆阳之战中成名，随后迅速统一中国。他与刘邦不同，他更注重与当地地主豪强的合作，因此东汉的权力结构中，地方豪强势力极大。他推行轻徭薄赋，使社会经济迅速恢复，被后世称为"光武中兴"。
- **核心事件志**：
    - **重建汉室 (公元25年)**：终结新朝后的乱局。
    - **光武中兴**：通过制度优化恢复帝国活力。
- **战争档案**：
    - **昆阳之战**：以少胜多，摧毁王莽主力。

### 东汉中后期皇帝 (明帝至献帝)
- **世系与关键特质**：
    - **明帝 (刘庄)**、**章帝 (刘炟)**：明章之治，东汉前期的稳定繁荣期。
    - **和帝 (刘肇)**：幼年继位，窦太后临朝，外戚专权开始。
    - **殇帝 (刘隆)**：出生百日继位，在位不足一年即夭折。
    - **安帝 (刘祜)**：邓太后临朝后期，外戚与宦官矛盾显现。
    - **顺帝 (刘保)**：宦官扶持上位，宦官势力膨胀。
    - **冲帝 (刘炳)**、**质帝 (刘缵)**：均幼年继位，在位时间极短，梁冀专权。
    - **桓帝 (刘志)**：依靠宦官除掉梁冀，宦官专权达到顶峰，党锢之祸开始。
    - **灵帝 (刘宏)**：极致的腐败，实行"卖官鬻爵"，第二次党锢之祸，导致政府彻底丧失信誉。
    - **献帝 (刘协)**：东汉最后一任皇帝。在位期间完全被曹操掌控，名为皇帝实为囚徒，标志着帝国彻底崩塌。
- **权力死循环**：从和帝开始，皇帝多幼年继位，导致"外戚临朝—皇帝长大依靠宦官夺权—宦官专权"的恶性循环。
- **重大事件**：**黄巾起义 (184年)**
    导致地方军权下移，军阀割据。

# 三国

## 曹丕 (魏文帝)
- **传记**：曹操之子。他不仅是政治上的投机者，也是文学上的才子。他通过精密的政治布局，在汉献帝面前建立起不可动摇的权威，最终篡汉立魏。他采纳陈群建议推行九品中正制，导致门阀政治在后世盛行。
- **核心事件**：**篡汉 (220年)**
    结果：终结东汉，建立魏国。

## 刘备 (蜀汉昭烈帝)
- **传记**：白手起家的政治家。他以"仁义"作为核心政治品牌，在乱世中吸引了大量追随者。在经历了多次失败后，在诸葛亮的辅佐下夺取益州。他一生致力于"兴复汉室"，虽然最终未能统一，但其精神符号影响深远。
- **核心事件**：**三顾茅庐 / 隆中对**
    制定统一蓝图。
- **主要战争**：**夷陵之战**
    结果：大败，蜀汉元气大伤。

## 孙权 (吴大帝)
- **传记**：江东的守护者。他在年轻时便继承父兄基业，凭借对长江地理的极致利用和外交上的灵活（在魏蜀之间反复周旋），稳固了吴国的地位。
- **主要战争**：**赤壁之战 (208年)**
    结果：击败曹操，奠定三分天下。

# 隋

## 杨坚 (隋文帝)
- **传记**：南北朝分裂时代的终结者。他以极其高效的行政手段统一全国，推行均田制和三省六部制。最重要的是，他创立了科举制，打破了门阀对官职的垄断，为之后一千年的文官制度铺平道路。
- **基建志**：**开皇律** (法制统一)。

## 杨广 (隋炀帝)
- **传记**：中国历史上最具争议的皇帝。他拥有极强的执行力，但缺乏政治同情心。他在古运河基础上疏浚贯通大运河，将南北经济彻底绑定；但同时在位期间多次征讨高句丽，导致民力枯竭，引发全国性起义。他死于部下的背叛，但他的大运河却成了后世千年的经济命脉。
- **基建志**：**隋唐大运河 (605-610年)**
    目的：沟通海河、黄河、淮河、长江、钱塘江五大水系。

# 唐

## 李渊 (高祖)
- **传记**：在隋末乱局中起兵，通过稳健的外交和军事手段迅速统一关中并建立唐朝。

## 李世民 (太宗)
- **传记**：中国历史上最顶级的政治操盘手。通过"玄武门之变"残酷夺权，但登基后迅速转型为宽容、勤政的君主。他建立的"贞观之治"核心在于"纳谏"——允许大臣批评皇帝。他在军事上彻底击败东突厥，使唐朝成为当时的全球超级大国。
- **核心事件志**：
    - **玄武门之变 (626年)**：清除政治对手，确保权力集中。
    - **贞观之治**：通过高效治理实现人口与经济的爆炸式增长。
- **战争档案**：
    - **征讨突厥**
    结果：确立"天可汗"地位。

## 武则天 (武周)
- **传记**：历史上唯一正统的女帝。她通过极其残酷的手段（如设立酷吏、清洗门阀）强行推开权力之门。但在执政期间，她大力支持科举，让大量寒门子弟进入政权，客观上削弱了贵族势力，增强了中央集权。
- **核心事件志**：
    - **建立武周 (690年)**：正式称帝。
    - **推广科举**：扩招人才，打破门阀。

## 李隆基 (玄宗)
- **传记**：一个典型的"前期圣君，后期昏君"。前半生他励精图治，开创了"开元盛世"，使唐朝达到文化与经济的顶点。后半生他沉溺于杨贵妃的温情与李林甫的谄媚，导致政治腐败，最终引发安史之乱。
- **核心事件志**：
    - **开元盛世**：中国古代繁荣的极致。
    - **安史之乱 (755-763年)**
    结果：唐朝由盛转衰，陷入藩镇割据。
- **战争档案**：
    - **安史之乱**：对战安禄山、史思明
    结果：中央权力崩溃，藩镇兴起。
- **基建志**：**大明宫**
    象征盛唐的至高权力。

## 中晚唐皇帝 (肃宗至哀帝)
- **世系概览**：肃宗（李亨）→ 代宗（李豫）→ 德宗（李适）→ 顺宗（李诵）→ 宪宗（李纯）→ 穆宗（李恒）→ 敬宗（李湛）→ 文宗（李昂）→ 武宗（李炎）→ 宣宗（李忱）→ 懿宗（李漼）→ 僖宗（李儇）→ 昭宗（李晔）→ 哀帝（李柷）
- **总结性传记**：这一时期的皇帝大多沦为两种力量的玩物：**宦官**（掌握禁军，可废立皇帝）与**藩镇**（掌控地方财税与军队）。尽管有宪宗的"元和中兴"、武宗的"会昌中兴"、宣宗的"大中之治"，但整体趋势是不可逆的崩溃。

# 宋

## 赵匡胤 (太祖)
- **传记**：军人出身的政治天才。在陈桥兵变后登基，面对此前千年的军阀乱局，他采取了极其巧妙的"杯酒释兵权"，通过金钱和爵位换取禁军高级将领的兵权，彻底解决了军队威胁。他确立了"强干弱枝"的政策，将权力高度集中于皇帝，并大力提拔文官，开创了中国历史上文治最盛的时代。
- **核心事件志**：
    - **陈桥兵变 (960年)**：通过军事政变建立北宋。
    - **杯酒释兵权**：和平地将禁军高级将领的军事权力收归中央。
- **战争档案**：
    - **统一南方**：通过外交与军事压力，逐步消除割据政权。
- **基建志**：
    - **开封城建设**：打造世界顶级商业都市。

## 赵光义 (太宗)
- **传记**：在太祖的阴影下执政，性格多疑且好胜。他完成了南方的最终统一（灭北汉），但在北方面对辽国时，高梁河之战惨败，意识到无法通过军事手段彻底收复燕云十六州。
- **核心事件志**：
    - **灭北汉 (979年)**：基本完成中原统一。
    - **高梁河之战**：伐辽大败，太宗本人负伤逃命。

## 赵恒 (真宗)
- **传记**：性格温和偏保守的守成之君。在辽国大军南下时，在寇准力劝下亲征澶州，最终签订了著名的"澶渊之盟"，以岁币换取和平。这一政策虽然被后世指责为屈辱，但在客观上保证了北宋长期的经济繁荣与百年和平。
- **核心事件志**：
    - **澶渊之盟 (1005年)**
    结果：维持宋辽百年和平，推动双边贸易发展。

## 赵顼 (神宗)
- **传记**：一位试图通过制度改革挽救帝国的皇帝。在面对日益严重的财政危机和地主兼并时，他重用王安石推行"新法"。王安石的改革触动了整个官僚阶层的利益，导致朝廷陷入剧烈的"新旧党争"。神宗的悲剧在于他拥有改革的决心，但未能处理好改革与权力斗争的关系。
- **核心事件志**：
    - **王安石变法 (熙宁变法)**
    核心：青苗法、保甲法等。

## 赵构 (高宗)
- **传记**：在极端的危机中生存的君主。经历了"靖康之变"的耻辱，在南方建立临安政府。他一生处于巨大的压力之中，但其核心政治逻辑是"求稳"而非"北伐"。他通过排挤岳飞等强硬派，试图通过外交手段换取生存空间，虽然维持了南宋的繁荣，但也失去了统一的契机。
- **主要战争**：**抗金战争**
    结果：通过绍兴和议达成妥协。

### 宋朝主要战争
- **靖康之变 (1127年)**：金军攻陷开封，徽钦二帝被掳，北宋灭亡。
- **蒙宋战争 (1235-1279年)**：面对蒙古帝国的全面进攻，最终在崖山海战中彻底灭亡。

# 元

## 忽必烈 (世祖)
- **传记**：蒙古帝国史上最成功的政治转型者。他意识到单纯的掠夺无法维持长久统治，于是决定"入主中原"。他建立大元，沿用汉人的行政体制，同时设立"行省"制度，将帝国划分为多个行政区，这一制度深深影响了后世。他一方面维持蒙古传统，另一方面通过宗教宽容和全球贸易（丝绸之路）将中国与西方紧密连接。
- **核心事件志**：
    - **建立大元 (1271年)**：确立中国式王朝体制。
    - **设立行省制**
    结果：加强了中央对广袤领土的控制。
- **战争档案**：
    - **灭宋战争**：通过长达数十年的围攻与战略压力，最终灭亡南宋。

### 元朝主要战争
- **灭南宋战争 (1268-1279年)**：元军南下，最终在崖山灭宋，统一全国。
- **元末农民起义**：红巾军起义
    结果：元朝崩溃，退回漠北。

> **说明**：蒙古三次西征（成吉思汗西征、拔都西征、旭烈兀西征）发生在大蒙古国时期（1219-1260年），早于1271年元朝建立，属于蒙古帝国扩张史，不计入元朝本身的战争。

# 明

## 朱元璋 (太祖)
- **传记**：中国历史上最极端的中央集权构建者。从一个赤贫的乞丐和和尚成长为开国之君，这使他极度仇视地主阶级和腐败官员。为了绝对控制权力，他采取了惊人的手段：废除丞相制度（让皇帝直接管事）、设立锦衣卫（特务机构）。他在位期间通过大规模的政治清洗（胡惟庸、蓝玉案）除掉了所有潜在威胁。
- **核心事件志**：
    - **废丞相 (1380年)**
    结果：皇权达到历史巅峰。
    - **设立锦衣卫**
    结果：建立起严密的特务监控体系。
- **基建志**：
    - **南京城建设**：建立第一座首都。

## 朱棣 (成祖)
- **传记**：通过血腥政变（靖难之役）夺权的篡位者。他拥有极强的军事才干和开拓精神。他将都城迁至北京，不仅是为了巩固北方边防，更是为了将权力中心向北移。他派遣郑和七次下西洋，将明朝的影响力扩散到非洲东岸，但随后的海禁政策却使中国逐渐走向封闭。
- **核心事件志**：
    - **迁都北京 (1421年)**
    结果：确立了北京作为权力中心的地位。
    - **郑和下西洋 (1405-1433年)**
    目的：展示国威，建立朝贡贸易体系。
- **基建志**：
    - **紫禁城 (1420年完工)**
    世界上最著名的皇宫建筑群。

## 朱由检 (崇祯)
- **传记**：一个勤勉但绝望的末代皇帝。他试图通过极端的节俭和严厉的行政手段挽救崩溃的帝国，但面对内忧（李自成、张献忠）与外患（后金/清），他表现得过于刚愎自用，且在用人上存在重大失误。他的自缢不仅是一个人的结局，更是整个明代体制的终结。
- **核心事件志**：
    - **李自成攻陷北京 (1644年)**
    结果：明朝灭亡。

### 明朝主要战争
- **靖难之役 (1399-1402年)**：燕王朱棣起兵夺权，最终攻入南京。
- **土木堡之战 (1449年)**：明军惨败于瓦剌，明英宗被俘
    结果：标志着明朝军事优势的丧失。
- **万历朝鲜战争 (1592-1598年)**：援助朝鲜抗日
    结果：维持了东亚秩序。

# 清

## 努尔哈赤 / 皇太极
- **传记**：后金的奠基者。努尔哈赤通过建立"八旗制度"，将社会组织与军事组织合一，构建了极强的动员能力。皇太极则通过改号"大清"和学习汉制，将单纯的部落联盟转型为正式的国家机器。

## 顺治帝
- **传记**：入关之主。在多尔衮的辅佐下，初步统一中国，尝试融合满汉文化。

## 康熙帝
- **传记**：在位61年的长寿且勤勉的君主。他通过平定三藩、收复台湾，彻底消除了入关后的国内割据。在外交上，他通过与俄国的《尼布楚条约》明确了东北边界。他的统治特点是"包容与强势"的结合，开创了康乾盛世。
- **核心事件志**：
    - **平三藩 (1673-1681年)**
    结果：削弱地方割据势力。
    - **收复台湾 (1683年)**
    结果：将台湾正式纳入版图。
- **战争档案**：
    - **雅克萨之战**
    对战俄国
    结果：胜利，签订尼布楚条约。

## 雍正帝
- **传记**：清朝最勤政且最残酷的皇帝。他意识到康熙时期的繁荣掩盖了财政危机，于是推行"摊丁入亩"和"火耗归公"，极大增加了国家收入。为了极速提高决策效率，他设立了"军机处"，将权力从内阁转移到自己的随侍近臣手中。
- **核心事件志**：
    - **设立军机处 (1729年)**
    结果：使皇权达到了极致的微观控制。
    - **摊丁入亩**
    结果：减轻农民人身束缚，增加税收。

## 乾隆帝
- **传记**：盛世的巅峰与衰落的起点。他在位期间通过"十全武功"将中国疆域推至最大。然而，在极度的自信与繁荣中，他纵容和珅等贪官横行，且在外交上采取封闭政策，导致清朝在工业革命前夜失去了转型的机会。
- **核心事件志**：
    - **四库全书编纂**
    结果：系统整理历代典籍，同时在编纂过程中查禁、删改了大量不利于清朝统治的书籍，与文字狱相辅相成。
- **战争档案**：
    - **平定准噶尔**
    结果：彻底统一新疆。

## 晚清皇帝 (嘉庆至宣统)
- **总结性传记**：面对西方工业文明的冲击，这一时期的皇帝逐渐失去了对局面的掌控。
- **嘉庆帝**：诛杀和珅，整顿吏治，但无法扭转清朝衰落的大趋势。
- **道光帝**：面对鸦片战争，在保守与改革之间犹豫不决。
- **咸丰帝**：经历了太平天国与第二次鸦片战争，帝国陷入极度混乱。
- **同治帝**：两宫太后垂帘听政，洋务运动开始。
- **光绪帝**：试图通过"戊戌变法"挽救国家，但被慈禧太后囚禁。
- **宣统帝 (溥仪)**：末代皇帝，随着辛亥革命的爆发，在1912年被迫退位。

### 清朝主要战争
- **鸦片战争 (1840-1842年)**
    结果：签订《南京条约》，中国进入半殖民地半封建社会。
- **太平天国运动 (1851-1864年)**：中国历史上规模最大的农民起义，严重动摇清朝统治。
- **甲午战争 (1894-1895年)**
    结果：签订《马关条约》，彻底暴露清朝的腐朽。
- **八国联军侵华 (1900年)**
    结果：签订《辛丑条约》，清政府完全沦为列强统治工具。

### 清朝主要建筑
- **圆明园**
    万园之园，中西合璧的极致，后被英法联军焚毁。

# 近代与新中国

## 关键领导人
- **孙中山**：三民主义奠基人，通过辛亥革命终结了两千年的帝制，建立了中华民国。
- **袁世凯**：北洋军阀之首，试图通过称帝恢复君主制，导致中国进入军阀割据时代。
- **蒋介石**：国民党领袖，在抗战中领导正面战场，但在随后的解放战争中被共产党击败。
- **毛泽东**：中国共产党领导人。提出了"农村包围城市"战略，领导新民主主义革命，最终在1949年建立了中华人民共和国。

## 近代重大战争
- **抗日战争 (1931-1945年)**：面对日本法西斯侵略，经历了从局部抗战到全面抗战的十四年战争
    结果：中国赢得胜利。
- **解放战争 (1946-1949年)**：通过三大战役（辽沈、淮海、平津）摧毁国民党军队主力
    结果：中华人民共和国成立。
